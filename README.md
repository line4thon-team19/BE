# 👑 한글대왕  
아이들의 바른말 습관, **실시간 받아쓰기 배틀**로 완성  
**바른말·맞춤법 학습형 받아쓰기 배틀 게임 웹 서비스**

<br/>

2025.10.11 ~ 2025.11.14

<br/>

[![Project Link](https://img.shields.io/badge/Project%20Site-hangeul--daewang-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://hangeul-daewang.vercel.app/)

<br>

### 프로젝트 요약

**해결하고자 하는 문제**
> 디지털 환경 확산으로 인해  
> 초등학생·청소년들의 **바른말·맞춤법 감각이 약화되고**,  
> 학교 내 받아쓰기 수업 시간은 지속적으로 감소하고 있습니다.

> 또한 교사는 한정된 수업 시간 속에서  
> **학생 개개인에게 맞춤형 피드백을 제공하기 어려운 상황**입니다.  
>  
> 이에 따라 더 효율적이고 재미있는 언어 학습 시스템의 필요성이 대두되고 있습니다.

<br>

**서비스 개요**

> **한글대왕**은  
> 아이들이 자연스럽게 바른말과 맞춤법을 익힐 수 있도록 설계된  
> **실시간 받아쓰기 배틀 기반 학습 서비스**입니다.

> 게임 요소를 접목해 학습 몰입도를 높이고,  
> 실시간 경쟁을 통해 동기부여와 학습 효과를 극대화합니다.

**주요 기능**
- [x] 실시간 1:1 배틀 받아쓰기
- [x] 문장 듣고 받아쓰기
- [x] 라운드 별 정답 여부 및 해설 제공
- [x] 연습 모드 / 배틀 모드
- [x] 게임 결과 카카오톡 공유 기능
- [x] EBS 사이트 리다이렉션


<br>

**활용한 핵심 기술**
> `Node.js` · `Express` · `Redis` · `MySQL`  
> `Socket.IO(WebSocket)` · `React` · `Vercel`

<br>

**기대되는 학습 효과**  
> 딱딱한 맞춤법 공부를 벗어나  
> **재미로 배우는 몰입형 학습 경험**을 제공합니다.
